# Maintainers

## Current Maintainer

| Role | GitHub | Scope |
| --- | --- | --- |
| Project owner and maintainer | [@AwayerCode](https://github.com/AwayerCode) | Technical direction, security, releases, licensing, and community operations |

The project currently has one maintainer. This is a documented continuity and
review risk, not the intended end state. See [GOVERNANCE.md](GOVERNANCE.md) for
the plan to add independent maintainers before v1.0.

## Responsibilities

- Keep public capability claims aligned with tested platform evidence.
- Review changes involving input interception, native ownership, permissions,
  privacy, and release integrity.
- Respond to private security reports and coordinate disclosure.
- Maintain repository settings, branch protection, workflow permissions, and
  release credentials.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md) and [GOVERNANCE.md](GOVERNANCE.md).

## Changes

Maintainer appointments, role changes, and departures are recorded here after
the process in [GOVERNANCE.md](GOVERNANCE.md) is complete. Access must be
removed when a maintainer leaves a role that requires it.
