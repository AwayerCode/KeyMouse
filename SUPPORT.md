# Support

KeyMouse is pre-alpha. There is no installable release, supported binary,
compatibility promise, or production support service yet.

## Documentation

- Product scope and current status: [README.md](README.md)
- Research and platform evidence: [docs/research.md](docs/research.md)
- Repository and open-source standards:
  [docs/open-source-strategy.md](docs/open-source-strategy.md)
- Contribution process: [CONTRIBUTING.md](CONTRIBUTING.md)
- Security policy: [SECURITY.md](SECURITY.md)

## Questions and Design Discussion

Use the repository's GitHub Issues for public, searchable questions and design
discussion. GitHub Discussions is not yet enabled. Include the platform,
architecture, runtime versions, backend, permission state, and sanitized
reproduction steps when relevant.

Do not post raw input contents, window titles, application data, credentials,
or other personal information.

## Bug Reports

Open a bug report through the repository's issue templates and state whether
the behavior was reproduced on real hardware. If the project has no
implementation for the affected feature, describe the expected contract or
research gap instead of presenting it as a regression.

## Security Reports

Report suspected vulnerabilities only through
[SECURITY.md](SECURITY.md). Do not open a public security issue.

## Conduct Reports

Report conduct incidents through the private route described in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not include sensitive details in a
public issue.

## Response Expectations

Replies are best effort. The project does not currently provide an SLA,
commercial support, guaranteed response time, or guaranteed fix schedule.
